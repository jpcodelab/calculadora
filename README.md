## 📌 Descripción
Calculadora web sencilla para dividir una cuenta entre varias familias, aplicando ponderación por adultos y niños.  
Compatible con **iPhone** y **Android**, accesible desde cualquier navegador móvil.

### 👨‍👩‍👧‍👦 Configuración actual:
- **Total ponderado:** 6,5 unidades (5 adultos + 3 niños)
- **Familias:**
  - Ana → 1 unidad
  - Carlos, Celia + Clara → 2,5 unidades
  - JP, Bea + André y Tomás → 3 unidades

La fórmula utilizada es:
pago_familia = (unidades_familia / 6.5) × total_cuenta
